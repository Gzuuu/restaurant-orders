# 🍽️ Restaurant Orders  

## 📋 Descrição Breve  
Este projeto é uma ferramenta de construção de cardápios, que considera restrições alimentares e a disponibilidade dos ingredientes em estoque. Foi desenvolvido durante meus estudos com Python, permitindo o aprofundamento em conceitos como Hashmaps e estruturas de dados avançadas.  

## 🛠️ Como Rodar o Projeto  
1. Clone o repositório:  
   ```bash  
   git clone https://github.com/Gzuuu/restaurant-orders.git  
   ```  
2. Entre na pasta do projeto:  
   ```bash  
   cd restaurant-orders  
   ```  
3. Instale as dependências:  
   ```bash  
   python3 -m pip install -r dev-requirements.txt  
   ```  
4. Para executar os testes:  
   ```bash  
   python3 -m pytest  
   ```  

## 💻 Tecnologias Utilizadas  
- **📝 Linguagem**: Python  
- **🔍 Bibliotecas**: Pytest  

## ⚙️ Funcionalidades  
- 📖 Construção de **cardápios personalizados** considerando restrições alimentares.  
- 🛒 Controle da **disponibilidade de ingredientes** no estoque.  

## 🌟 Principais Aprendizados  
- ⚡ Prática de **Hashmaps** utilizando `Dict` e `Set` do Python.  
- 🧩 Aplicação de conceitos de **orientação a objetos** (OOP).  
- ✅ Escrita de testes utilizando **Pytest**.
